# Color

컬러 변수는 Figma와 같은 세 컬렉션으로 나뉘고, 위 단계가 아래 단계를 참조합니다.

```
Semantic  --color-primary-default
   ↓ 참조
Theme     --color-primary-600
   ↓ 참조
Primitive --color-red-600 = #F43D2D
```

- **Semantic** — 용도에 따라 이름 붙인 색상입니다 (`--color-primary-default`, `--color-label-primary` 등). **컴포넌트는 Semantic 토큰만 사용합니다.**
- **Theme** — 브랜드 팔레트(`primary`, `secondary`)를 Primitive에 연결합니다. 브랜드 컬러를 바꿀 때는 이 단계만 수정합니다.
- **Primitive** — 실제 색상 값입니다. 컴포넌트에서 직접 쓰지 않습니다.

CSS에서도 값을 복사하지 않고 `var()`로 연결하므로, 아래 단계 값을 바꾸면 위 단계 전체에 반영됩니다.
견본의 `→`는 참조하는 변수이고, 견본을 클릭하면 `var(--...)` 코드가 복사됩니다.
